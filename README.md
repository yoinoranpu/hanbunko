# 半分こ

写真2枚をL判1枚に配置し、JPEG・PDFに書き出すブラウザアプリです。
写真と編集内容はブラウザのIndexedDBに保存し、写真をサーバーへ送信しません。フォント取得にはGoogle Fontsへの接続があります。

## 開発・検証

```sh
npm ci
npm run dev
npm run build
npx playwright install chromium
npm run test:e2e
```

既存のChromiumを使う場合は `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e` で指定できます。
テストはPCとスマホ相当の画面で、保存・復元・削除・書き出しと失敗時の回復を確認します。iPhoneのSafari実機と実際の印刷は別途確認してください。

## 保存・削除・印刷

- 写真と編集内容はこのブラウザに自動保存します。失敗時は案内と再試行ボタンを表示します。
- 写真を選択し「削除」で、その写真と編集内容をブラウザの保存領域から削除できます。左右は別々です。書き出し済みのJPEG・PDFや元の写真ファイルは削除しません。
- 削除時は待機中の自動保存を中止し、処理中の書き込みが終わってから削除します。削除失敗時は写真を残し、再試行を案内します。
- ブラウザのデータ削除や保存容量制限によって、自動保存した写真が失われることがあります。必要な完成画像はJPEG・PDFとして保存してください。
- PDFはL判・横向き・倍率100％で印刷します。JPEGは印刷サービス側でL判と切り抜き範囲を確認してください。プリンターごとの余白や拡大があるため、まず試し刷りしてください。

ブラウザのページ拡大を許可しています。写真の配置領域内のピンチ操作は写真の拡大縮小です。
